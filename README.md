## Project experience

My technical contributions include development and integration across the
following systems.

### Foreign trade and mining analytics — data platform

Integrates customs records, mining-production data and international sources for
extractive-sector analysis. The work connects data acquisition, validation and
transformation with traceable PostgreSQL layers, a FastAPI service, a web
application and reproducible reports. Automated tests and continuous integration
check data contracts and application integration.

### Tax revenue forecasting — experimental research

Builds nominal and inflation-adjusted revenue series from DIAN and DANE data.
Compares SARIMA, machine-learning and neural models at 1, 3, 6 and 12-month
horizons using chronological out-of-sample evaluation. The workflow preserves
data versions, predictions and metrics and supports command-line execution and
research reporting. No model has been promoted to operational use.

### Tax risk and customs selectivity — suite in development

Combines batch tax analysis and customs-event processing to support review
prioritization. The development brings together graph and tensor models,
rule-based assessment, APIs and web interfaces, with experiment tracking and
model lifecycle management. Orchestration, monitoring and deployment
infrastructure are part of the development scope; outputs support human review.

### Tax registry consistency — standalone analytical component

Combines versioned rules, latent representations and tensor analysis to diagnose
registry inconsistencies. Covers data contracts, validation, fitting, evaluation
and inference, with verifiable artifacts, HTML reports, tests and an end-to-end
example using synthetic data. Its diagnostics are not estimates of
noncompliance probability.
